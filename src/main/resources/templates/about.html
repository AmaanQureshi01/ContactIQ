Why I Built ContactIQ

ContactIQ is a full-stack cloud contact management web application designed to keep personal and professional connections organized, searchable, and secure.

Tech Stack Used

Java Spring Boot Spring Security OAuth2 Thymeleaf Tailwind CSS MySQL

Learning & Architecture

Built from scratch to practice real-world backend patterns: role-based access control, BCrypt password hashing, Google & GitHub OAuth2 login, SMTP OTP verification, and clean MVC separation.

User-Friendly Design

Designed with responsive Tailwind CSS layouts, persistent Light & Dark themes, instant multi-field search, favorite contact pinning, and one-click Excel export.
